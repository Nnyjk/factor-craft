# Factor 世界观设定

## 核心概念：什么是 Factor？

Factor（因子）是构成这个世界的本质能量。它是所有物质、魔法、生命的基础构成单位。

### 起源传说
在世界诞生之前，虚空之中只有纯粹的混沌能量。
原初之灵将混沌能量拆解为五种基础属性，每种属性都拥有独特的性质和形态，这就是五大基础Factor：
- **火Factor**：代表能量、热量、破坏与创造
- **水Factor**：代表流动、变化、治愈与融合
- **风Factor**：代表自由、速度、传递与连接
- **土Factor**：代表稳定、厚重、实体与承载
- **原初Factor**：代表混沌本身，是所有Factor的根源

### 世界运作原理
Factor 不断在世界中流动、转换、聚合：
1. 区块中天然存在 Factor 浓度，浓度越高，该属性的力量越强
2. Factor 可以从自然环境中提取，也可以通过合成创造出更高级的复合Factor
3. Factor 遵循守恒定律：既不会凭空产生，也不会凭空消失，只会从一种形态转换为另一种形态
4. 不同维度的 Factor 活性不同：主世界最稳定，下界充满能量，末地则是 Factor 最活跃的地方

## 因子系统设定

### 五大基础 Factor

| Factor类型 | 特性 | 常见来源 | 用途 |
|-----------|------|----------|------|
| 🔥 火因子 | 活跃、高温、能量属性 | 岩浆、火焰、下界 | 加热、烧制、能量供应 |
| 💧 水因子 | 流动、低温、治愈属性 | 河流、海洋、降雨 | 冷却、酿造、生命合成 |
| 🌪️ 风因子 | 高速、传递、连接属性 | 高空、云层、风暴 | 传输、加速、信号传递 |
| 🌍 土因子 | 稳定、厚重、实体属性 | 矿物、岩石、大地 | 建筑、合成、基础材料 |
| ⭐ 原初因子 | 混沌、稀有、本源属性 | 末地、远古遗迹、特殊结构 | 高级合成、突破、创造 |

### 因子等级体系
Factor 按照纯度和能量层级分为6个等级：
- **T1**: 基础级 - 直接从自然提取的低纯度Factor
- **T2**: 精炼级 - 经过第一次提纯的Factor
- **T3**: 浓缩级 - 高纯度浓缩Factor
- **T4**: 纯净级 - 几乎没有杂质的Factor
- **T5**: 本源级 - 接近属性本源的Factor
- **TΩ**: 创世级 - 理论上的最高等级，只有原初Factor能达到

## 世界背景故事

### 远古时代
上古文明已经掌握了Factor的使用方法，他们创造了辉煌的科技与魔法结合的文明，可以自由操控Factor来改变世界。
但是过度的Factor使用导致了世界平衡被打破，上古文明在一场Factor大爆炸中毁灭，大部分Factor知识随之消失。

### 现代世界
玩家作为探索者，在这个世界中重新发现Factor的使用方法：
- 你可以从自然中提取Factor
- 你可以合成更高级的Factor
- 你可以使用Factor创造物品、建造机器、释放能力
- 你甚至可以突破等级限制，达到创世级，重新掌握上古文明的力量

### 世界规则
- Factor 不会伤害人类，相反，人类可以通过训练来感知和操控Factor
- 职业系统是人类对Factor不同应用方向的探索：
  - **采集者**：擅长从自然中高效提取Factor
  - **合成师**：擅长将不同Factor合成为新的物质
  - **战士**：擅长将Factor注入身体获得超凡力量

## 游戏内物品 lore 设定

### 机器设备
- **Factor 提取器**：从区块中提取基础Factor的设备，模仿上古文明的提取技术
- **Factor 合成器**：将不同Factor按比例合成为复合Factor的设备
- **Factor 监控器**：可以查看区块中Factor浓度的设备，是上古文明遗留的技术碎片
- **Factor 储罐**：存储Factor的容器，使用特殊材质防止Factor逸散

### 物品道具
- **Factor 结晶**：高纯度Factor固化后的形态，可以方便存储和运输
- **引导书**：记录Factor基础知识的手册，帮助新手快速入门
- **职业徽章**：代表不同职业的身份象征，注入了特殊的Factor能量
