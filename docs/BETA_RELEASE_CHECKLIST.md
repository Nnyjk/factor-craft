## 📋 发布流程

### 发布前检查

1. [x] 确认版本号 (`v0.2.0-beta`)
2. [x] 更新 CHANGELOG.md
3. [x] 运行完整测试套件
4. [x] 检查 Git 状态干净

### 创建发布

```bash
# 创建标签
git tag -a v0.2.0-beta -m "Release v0.2.0-beta"

# 推送标签
git push origin v0.2.0-beta
```

### GitHub Release

1. 进入 [Releases](https://github.com/Nnyjk/factor-craft/releases)
2. 点击 "Draft a new release"
3. 选择标签 `v0.2.0-beta`
4. 填写发布说明（从 CHANGELOG 复制）
5. 上传构建的 jar 文件
6. 发布！

### 发布后

- [ ] 提交到 CurseForge (待审核)
- [ ] 提交到 Modrinth (待审核)
- [ ] 公告社区
