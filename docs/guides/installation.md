# Factor Craft 安装指南

> **版本：** Alpha 1.0.0  
> **Minecraft:** 1.21.4  
> **Fabric:** 0.16.10+

---

## 📋 前置要求

- Minecraft 1.21.4
- Fabric Loader 0.16.10+
- Fabric API 0.119.2+
- Java 21+

---

## 🚀 安装步骤

### 1. 安装 Fabric
1. 下载 Fabric Installer: https://fabricmc.net/use/installer/
2. 运行安装程序，选择 Minecraft 1.21.4
3. 点击"Install"

### 2. 安装 Fabric API
1. 下载：https://modrinth.com/mod/fabric-api
2. 放入 `.minecraft/mods/`

### 3. 安装 Factor Craft
1. 下载 `factor-craft-0.1.0.jar`
2. 放入 `.minecraft/mods/`

### 4. 启动游戏
1. 选择 "Fabric 1.21.4" 配置文件
2. 点击"Play"

---

## 🎮 快速开始

### 第 1 天
- 收集铜矿石 (10+)
- 制作铜工具
- 建立庇护所

### 第 2-3 天
- 建造基础共振炉
- 生产青铜锭
- 制作 Factor 剑 T1

### 第 4-7 天
- 前往下界
- 建造维度结晶器
- 生产维度级材料

### 第 8-14 天
- 进入末地
- 建造远古合成阵
- 挑战 Boss

---

## 🔧 故障排除

**Mod 无法加载：**
- 确认 Fabric 已安装
- 检查 Fabric API 版本
- 查看日志文件

**多方块无法形成：**
- 确认方块位置正确
- 检查核心方块位置

**游戏崩溃：**
- 增加内存分配 (2GB+)
- 更新显卡驱动
- 提交 Issue 到 GitHub
