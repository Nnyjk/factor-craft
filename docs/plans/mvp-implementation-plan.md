# Factor Craft MVP 实施计划

> **版本：** 1.0  
> **日期：** 2026-03-09  
> **目标：** 完成 Factor Craft 核心 MVP，包含基础 Factor 循环、维度系统、多方块结构

## 📋 项目概述

基于已完成的核心设计文档，实现 Factor Craft 的 MVP 版本，包含：
1. 基础 Factor 循环系统（吸收/释放/传递）
2. 三维度基准值体系
3. 多方块结构实现
4. 主线任务引导

**设计文档依据：**
- docs/16_dimensions_and_biomes.md (维度设计)
- docs/17_factor_cycle_structures.md (Factor 循环)
- docs/18_disasters_and_events.md (灾害系统)
- docs/02_materials_traits_enchants_buffs.md (材料系统)
- docs/03_technology_multiblock.md (科技树)

#### 任务 1.2: 维度基准值系统实现
```
任务描述：
- 实现 DimensionType 枚举（OVERWORLD=0.5, NETHER=1.5, END=3.0）
- 实现 FactorWorldState 类（存储当前 Factor 值）
- 实现 TideSystem 类（潮汐计算公式）
- 实现 DimensionManager 类（维度管理）

核心公式：
- Factor(t) = baseValue + amplitude × sin(2π × t / period)
- 主世界：base=0.5, amplitude=0.2, period=192000 tick
- 下界：base=1.5, amplitude=0.6, period=96000 tick
- 末地：base=3.0, amplitude=1.2, period=288000 tick

验收标准：
- [ ] DimensionType 枚举正确
- [ ] FactorWorldState 可存储和读取 Factor 值
- [ ] TideSystem 计算正确（单元测试验证）
- [ ] DimensionManager 可获取当前维度信息
- [ ] Git 提交：feat: implement dimension base value system
```

核心类：

## 🚨 风险与应对

### 风险 1: 多方块结构复杂度
**风险：** 多方块检测和形成逻辑复杂，可能延期
**应对：** 优先实现基础框架，逐步添加复杂结构

### 风险 2: Factor 循环平衡
**风险：** Factor 产出/消耗平衡难以把握
**应对：** 先实现基础数值，后续通过 JSON 配置调整

### 风险 3: 跨维度同步
**风险：** 三维度 Factor 同步可能有性能问题
**应对：** 使用延迟加载和缓存机制
