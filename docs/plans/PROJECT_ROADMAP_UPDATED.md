## 🔄 工作流程

### 日常开发流程

```
1. 创建 Issue → 2. 分配任务 → 3. 创建分支
       ↓
4. 实现功能 → 5. 编写测试 → 6. 提交 PR
       ↓
7. Code Review → 8. 合并 → 9. 删除分支
```

### PR 审查流程

```
PR 提交 → 自动检查 → Code Review 专家审查 → 修改 (如需) → 合并
   |           |              |                    |
 模板验证   构建测试      质量检查            清理分支
```

### 发布流程

```
代码冻结 → 最终测试 → 打包构建 → 发布说明 → 平台发布
   |           |           |           |          |
停止新功能  回归测试   生成 JAR   编写文档   CurseForge 等
```
