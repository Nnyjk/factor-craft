# Factor Craft 递进式收获感系统设计

> 创建日期: 2026-03-22
> 核心理念: 升级让低级内容更轻松，里程碑给予质的飞跃，终极突破赋予"创造"体验

---

## 设计目标

1. **收获感递进** - 每升一级，获取上一级材料/物品变得更容易
2. **里程碑节点** - 每个等级设2-3个中间节点，解锁重大简化或提升
3. **终极突破** - 最高等级后设定难度极高的突破阶段，完成后获得"创造"体验

---

## 一、科技等级递进系统

### 1.1 等级定义

| 等级 | 名称 | 主题 | 解锁内容 |
|------|------|------|----------|
| T1 | 尘铜时代 | 基础机器、Factor 收集 | 提取器、消耗器、基础合成 |
| T2 | 暗影时代 | 多方块结构、材料升级 | 合成器、培育器、暗影钢 |
| T3 | 星尘时代 | 维度探索、高级合成 | 维度提取、星尘锭、职业觉醒 |
| T4 | 远古时代 | Boss 挑战、传奇装备 | 远古合金、高级职业能力 |
| T5 | 虚空时代 | 终极内容、突破准备 | 虚空结晶、完整职业能力 |
| TΩ | 创造时代 | 突破后 | 创造模式能力、无限制 |

### 1.2 递进式收获机制

**核心公式**: 
```
获取效率 = 基础效率 × (1 + 等级差 × 加成系数)
```

### 突破能力详细设计

#### 创生者 - 生命编织

**能力描述**: 消耗 Factor，直接创造任何已解锁的生物实体

**使用方式**:
- 右键空地：打开创造菜单，选择生物类型
- 可指定：等级、装备、自定义属性
- 可保存：保存自定义生物配置，一键召唤

**实用性**:
| 用途 | 效果 |
|------|------|
| 资源农场 | 无限生成牛/羊/鸡，获取肉、皮革、羊毛 |
| 刷怪塔 | 生成大量怪物，配合湮灭者玩家快速刷经验/掉落 |
| Boss 挑战 | 随时召唤 Boss 进行挑战或测试 |
| 宠物定制 | 创造带自定义名称/装备的宠物 |
| 村民交易 | 创造特定职业村民，获取稀有交易 |

#### 湮灭者 - 虚空吞噬

**能力描述**: 激活后，范围内所有敌对生物被瞬间消灭，掉落物正常生成

**使用方式**:
- 激活技能：选择范围（默认 32 格）
- 所有敌对生物：立即死亡
- 掉落物：正常掉落，可被收集

**实用性**:
| 用途 | 效果 |
|------|------|
| 高效刷怪塔 | 配合刷怪笼，一键清怪 |
| Boss 速刷 | 快速清理 Boss 附近的仆从 |
| 危险区域 | 瞬间清理洞穴/要塞的怪物 |
| 经验农场 | 配合经验修补，快速获取经验 |
| 材料收集 | 大量掉落物快速获取 |

#### 锻铸师 - 物质重塑

**能力描述**: 对任意物品/方块使用，打开属性编辑界面

**使用方式**:
- 对物品：修改附魔、耐久、属性修饰符
- 对方块：修改硬度、发光、自定义掉落
- 可保存：保存配置为模板，批量应用

**实用性**:
| 用途 | 效果 |
|------|------|
| 神装定制 | 创建任意附魔组合的装备 |
| 工具优化 | 无限耐久、自定义挖掘速度 |
| 方块创意 | 创建发光玻璃、不掉落的方块 |
| 礼物制作 | 创建带有自定义名称/描述的物品 |
| 地图制作 | 创建特殊方块用于冒险地图 |

### 职业协同

突破后玩家可以组队，发挥更强的效果：

| 组合 | 协同效果 |
|------|----------|
| 创生者 + 湮灭者 | 创生者生成怪物 → 湮灭者秒杀 → 高效刷资源 |
| 创生者 + 锻铸师 | 创生者创造生物 → 锻铸师赋予装备 → 定制军队 |
| 湮灭者 + 锻铸师 | 锻铸师制作神装 → 湮灭者穿戴 → 无敌战斗 |
| 三者合一 | 完整的资源循环体系 |

## 四、设计原则总结

1. **每升一级必须有收获感** - 不是新的东西，就是对旧东西的简化
2. **里程碑必须是质变** - 改变玩家游玩方式，不是简单的数值加成
3. **突破必须是终局目标** - 让玩家有明确的长期追求
4. **突破后要有创造体验** - 给玩家"我已经超越游戏"的感觉
