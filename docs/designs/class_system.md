# Factor Craft 职业体系设计

> 创建日期: 2026-03-20
> 状态: 设计中
> 核心关键词: 创生、湮灭、锻铸

---

## 设计理念

在废弃文明的遗迹中，幸存者发现了三种与 Factor 能量共鸣的道路。每条道路代表对 Factor 本质的不同理解：

- **创生** - 生命与生长的循环
- **湮灭** - 虚空与毁灭的归宿  
- **锻铸** - 转化与重塑的艺术

---

## 三大职业道路

### 🌿 创生者 (Genesis)

**核心理念**: Factor 是生命的种子，万物皆可繁衍

**世界观**: 创生者相信 Factor 是远古文明遗留的生命能量。他们学会引导这股力量，让荒芜的土地重新焕发生机，治愈伤痛，甚至创造全新的生命形态。

**风格**: 自然与科技融合，藤蔓缠绕的金属，发光的晶体植物

**核心属性**:
| 属性 | 说明 |
|------|------|
| 生命力 | 生命值上限 +Factor 再生速度 |
| 共鸣 | 召唤物强度 +治愈效果 |
| 生长 | 作物成熟速度 +被动生命恢复 |

---

### ⚫ 湮灭者 (Oblivion)

**核心理念**: Factor 是毁灭的余烬，万物终归于虚空

**世界观**: 湮灭者拥抱 Factor 中蕴含的毁灭之力。他们明白，只有通过破坏才能腾出空间让新事物诞生。他们驾驭虚空能量，将敌人分解为最原始的 Factor。

**风格**: 暗黑与虚空，紫黑裂纹，破碎的粒子效果

**核心属性**:
| 属性 | 说明 |
|------|------|
| 毁灭 | 伤害加成 +暴击率 |
| 虚空亲和 | Factor 技能消耗减少 +虚空伤害 |
| 熵增 | 击杀回复 +范围伤害加成 |

---

### ⚒️ 锻铸师 (Forge)

**核心理念**: Factor 是转化的媒介，万物皆可重塑

**世界观**: 锻铸师视 Factor 为最纯净的改造材料。他们精通将 Factor 注入物品，强化装备，改造方块，甚至重写物质的基本属性。

**风格**: 工业与符文，熔岩纹路，金属光泽

**核心属性**:
| 属性 | 说明 |
|------|------|
| 工艺 | 制造速度 +成品品质 |
| 强化上限 | 装备可强化次数上限 |
| 效率 | 机器工作效率 +燃料节省 |

每个职业拥有 **3 条天赋路线**，每条路线 **5 层天赋**：

```
Tier 1 (等级 5 解锁)  - 基础强化
Tier 2 (等级 10 解锁) - 机制扩展
Tier 3 (等级 20 解锁) - 核心能力
Tier 4 (等级 30 解锁) - 高级专精
Tier 5 (等级 50 解锁) - 终极天赋

## 技能系统

### 技能分类

```
主动技能: 需要手动释放，消耗 Factor
被动技能: 自动生效，无需操作
生活技能: 与日常活动相关，提供便利
```

### 技能栏位

- **主动技能栏**: 4 个 (可扩展至 6 个)
- **被动技能槽**: 3 个 (可扩展至 5 个)
- **生活技能**: 始终激活，无栏位限制

## 职业成长系统

### 等级体系

```
职业等级: 1-100

├── 新手阶段 (1-10)    - 基础属性成长，解锁职业选择
├── 成长阶段 (11-30)   - 天赋解锁，核心技能习得
├── 精通阶段 (31-50)   - 高级天赋，终极技能解锁
├── 大师阶段 (51-75)   - 属性突破，副职开启
└── 传奇阶段 (76-100)  - 传奇天赋，职业专属特性
```

### 升级消耗

**核心机制：双资源消耗升级**

升级需要同时消耗 **Minecraft 经验值** 和 **Factor 能量**：

```
升级消耗公式:
┌─────────────────────────────────────────────────────┐
│  经验消耗 = 基础值 × 等级系数                        │
│  Factor消耗 = 等级² × 职业系数                       │
│                                                     │
│  具体公式:                                          │
│  经验 = 100 × Level × 1.15^(Level/10)              │
│  Factor = Level² × 职业系数                         │
└─────────────────────────────────────────────────────┘

职业系数:
- 创生者: 1.0 (标准)
- 湮灭者: 1.2 (高消耗，高回报)
- 锻铸师: 0.8 (低消耗，稳定成长)
```

熵增: 每点 +2% 击杀回复，+1% 范围伤害

工艺: 每点 +2% 制造速度，+1% 品质概率
强化上限: 每点 +0.2 强化上限，+2% 成功率
效率: 每点 +2% 机器效率，-1% 燃料消耗
```

### 天赋点系统

**获取方式**:
- 每升 2 级获得 1 天赋点 (1-50 级)
- 每升 3 级获得 1 天赋点 (51-100 级)
- 里程碑额外奖励

**总计**:
- 1-50 级: 25 天赋点 + 里程碑奖励 = 约 35 点
- 51-100 级: 17 天赋点
- **总计**: 约 52 天赋点

**分配限制**:
- 每层天赋需要该层解锁
- 终极天赋 (Tier 5) 需要点满该路线前 4 层
- 三条路线可自由搭配，不限制专精

### 归元系统 (重置)

**解锁条件**: 等级 50+

**功能**: 重置所有属性点和天赋点，重新分配

**消耗**:
- 首次归元: 10,000 Factor
- 第二次: 50,000 Factor
- 第三次及以后: 100,000 Factor

**奖励**:
- 每次归元获得 **归元印记** ×1
- 归元印记可用于购买稀有外观/称号
- 归元后保留技能等级

## 职业转换

### 转换规则

- 玩家初始无职业
- **等级 10** 可选择第一职业道路
- **等级 30** 可选择开启第二职业 (副职)
- 副职只获得 **50% 的被动效果** 和 **生活技能**
- 转换职业需要消耗 Factor (见归元系统)
