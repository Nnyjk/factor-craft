## 吸收结构

### 基础共振炉 (T1, 3×5×3)

```
顶层 (Y+4):
┌───┬───┬───┐
│ R │ C │ R │
├───┼───┼───┤
│ C │ F │ C │
├───┼───┼───┤
│ R │ C │ R │
└───┴───┴───┘

中层 (Y+1 到 Y+3, 3 层):
┌───┬───┬───┐
│ W │   │ W │
├───┼───┼───┤
│   │   │   │
├───┼───┼───┤
│ W │   │ W │
└───┴───┴───┘

底层 (Y+0):
┌───┬───┬───┐
│ R │ H │ R │
├───┼───┼───┤
│ H │ H │ H │
├───┼───┼───┤
│ R │ H │ H │
└───┴───┴───┘

图例:
R = 粗坯级框架 (铜/青铜)
C = 共振线圈
F = 因子计核心
W = 输入仓
H = 输出仓

尺寸：3×5×3 (45 方块)
消耗：1000 点 Factor/批次
产物：Lv1→Lv2 材料
```

## 释放结构

```
所有层相同:
┌───┬───┬───┐
│ F │ C │ F │
├───┼───┼───┤
│ C │ I │ C │
├───┼───┼───┤
│ F │ C │ F │
└───┴───┴───┘

图例:
F = 粗坯级框架
C = 共振线圈
I = 输入仓 (物品)

尺寸：3×3×3 (27 方块)
产出：+50 Factor/批次 (×维度倍率)
```
