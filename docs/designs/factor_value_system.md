# Factor 数值体系设计

## 核心原则

**两个独立系统，各司其职**

---

## 1. 区块浓度 (Chunk Concentration)

### 定义
- **范围**：10-150
- **标准参照**：100
- **存储位置**：区块级

### 用途
- 区块内 Factor 存量
- 提取效率计算（浓度系数）
- 扩散系统

### 浓度系数
```
浓度系数 = 
  浓度 > 50  → ×1.2 (高浓度)
  浓度 30-50 → ×1.0 (正常)
  浓度 10-30 → ×0.8 (低浓度)
  浓度 < 10  → ×0.5 (枯竭)
```

### 生成逻辑
```
基础浓度：40-70
群系加成：-10 ~ +50
稀有高浓度：100-150 (5% 概率)
```

---

## 2. 维度活性系数 (Dimension Activity)

### 定义
- **基准值**：主世界 0.5 / 下界 1.5 / 末地 3.0
- **波动范围**：基准值 ± 幅度
- **存储位置**：维度级

| 维度 | 基准值 | 幅度 | 范围 | 周期 |
|------|--------|------|------|------|
| 主世界 | 0.5 | 0.2 | 0.3-0.7 | 8 天 |
| 下界 | 1.5 | 0.6 | 0.9-2.1 | 4 天 |
| 末地 | 3.0 | 1.2 | 1.8-4.2 | 12 天 |

### 用途
1. **跨维度传输倍率**
   ```
   倍率 = 发送端基准 / 接收端基准
   
   下界→主世界: 1.5/0.5 = 3.0x
   末地→主世界: 3.0/0.5 = 6.0x
   主世界→下界: 0.5/1.5 = 0.33x
   ```

2. **FactorTier（偏离度）**
   ```
   偏离度 = (当前活性 - 维度基准) / 维度基准
   
   DEPLETED:   < -50%
   LOW_ENERGY: -50% ~ -20%
   STABLE:     -20% ~ +20%
   HIGH_ENERGY: +20% ~ +50%
   OVERLOAD:   > +50%
   ```

3. **维度惩罚判定**
   - T1 材料生产推荐主世界
   - T2 材料生产推荐下界
   - T3+ 材料生产推荐末地

---

## 3. 系统交互

### 提取公式
```
实际提取 = 基础速率 × 维度活性系数 × 浓度系数 × 结构效率
```

### 示例
```
主世界，T1 星辰收集器，区块浓度 60：
- 基础速率：10
- 维度活性：0.5（当前潮汐值）
- 浓度系数：×1.2（浓度 60 > 50）
- 结构效率：100%
- 实际提取 = 10 × 0.5 × 1.2 × 1.0 = 6 Factor/tick
```

## 4. 数值对照表

| 概念 | 主世界 | 下界 | 末地 | 说明 |
|------|--------|------|------|------|
| 区块浓度标准 | 100 | 100 | 100 | 统一参照 |
| 维度活性基准 | 0.5 | 1.5 | 3.0 | 各自基准 |
| 传输倍率（出） | 0.33x | 3.0x | 6.0x | 相对主世界 |
| 推荐生产等级 | T1 | T2 | T3+ | 惩罚阈值 |

## 5. 常见问题

**Q: 为什么区块浓度不用维度基准值归一化？**
A: 区块浓度表示"存量"，维度活性表示"流动性"。两者物理意义不同，独立更清晰。

**Q: FactorTier 为什么用偏离度而不是绝对值？**
A: 不同维度的基准差异大（0.5 vs 3.0），绝对值无法统一判断。偏离度让各维度有统一的 Tier 标准。

**Q: 提取效率为什么同时受两个系统影响？**
A: 维度活性决定"该维度的 Factor 活跃程度"，区块浓度决定"该区块的 Factor 存量"。高活性维度 + 高浓度区块 = 最高产出。
