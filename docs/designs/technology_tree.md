# 科技树设计 (T1-T5)

> 基于 docs/03_technology_multiblock.md 和 docs/17_factor_cycle_structures.md

## T1: 粗坯科技

**解锁材料：** Lv1 粗坯级 (铜、青铜、石英强化木芯)

**科技节点：**
```
1. 基础 Factor 观测
   └─ 解锁：Factorometer
   └─ 前置：无
   
2. 基础共振炉
   └─ 解锁：Lv1→Lv2 材料生产
   └─ 前置：基础 Factor 观测
   
3. 基础共振器
   └─ 解锁：Factor 释放
   └─ 前置：基础共振炉
```

**多方块尺寸：** 3×5×3 (45 方块)

---

## T2: 工业科技

**解锁材料：** Lv2 工业级 (铁、下界石钢、玫瑰金)

**科技节点：**
```
1. 维度结晶器
   └─ 解锁：Lv2→Lv3 材料生产
   └─ 前置：基础共振炉 (T1)
   
2. 能量分解机
   └─ 解锁：高效 Factor 释放
   └─ 前置：基础共振器 (T1)
   
3. T1 传递器
   └─ 解锁：跨维度传输 (效率 80%)
   └─ 前置：维度结晶器
   
4. 下界传送门
   └─ 解锁：下界维度访问
   └─ 前置：维度结晶器
```

**多方块尺寸：** 5×7×5 (175 方块)

---

## T3: 维度科技

**解锁材料：** Lv3 维度级 (钴、阿迪特、玛玉灵)

**科技节点：**
```
1. 远古合成阵
   └─ 解锁：Lv3→Lv4 材料生产
   └─ 前置：维度结晶器 (T2)
   
2. 物质转化炉
   └─ 解锁：高产出 Factor 释放
   └─ 前置：能量分解机 (T2)
   
3. T2 传递器
   └─ 解锁：高效传输 (效率 85%)
   └─ 前置：T1 传递器
   
4. 世界稳定器
   └─ 解锁：区块级 Factor 控制
   └─ 前置：远古合成阵
   
5. 末地传送门
   └─ 解锁：末地维度访问
   └─ 前置：世界稳定器
```

**多方块尺寸：** 7×9×7 (441 方块)

## T4: 远古科技

**解锁材料：** Lv4 远古级 (远古合金、星辉晶、虚序复合材)

**科技节点：**
```
1. 仲裁反应堆
   └─ 解锁：Lv4→Lv5 材料生产
   └─ 前置：远古合成阵 (T3)
   
2. 维度裂变器
   └─ 解锁：超高 Factor 释放
   └─ 前置：物质转化炉 (T3)
   
3. T3 传递器
   └─ 解锁：超高效传输 (效率 90%)
   └─ 前置：T2 传递器
   
4. 潮汐反应釜
   └─ 解锁：终局合成
   └─ 前置：仲裁反应堆
   
5. 跨维度联动
   └─ 解锁：三维度 Factor 网络
   └─ 前置：T3 传递器 + 世界稳定器
```

**多方块尺寸：** 9×11×9 (891 方块)

2. T4 传递器
   └─ 解锁：完美传输 (效率 95%)
   └─ 前置：T3 传递器
   
3. 终局巨构
   └─ 解锁：最终抉择
