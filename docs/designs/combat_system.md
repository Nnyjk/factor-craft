## 🎯 设计目标

1. **Factor 驱动** - 所有战斗机制与 Factor 系统深度绑定
2. **维度差异** - 不同维度有不同的怪物和战斗体验
3. **科技递进** - T1-T5 武器对应不同游戏阶段
4. **无永久伤害** - 死亡惩罚可控，鼓励探索

---

## ⚔️ 武器系统

### 武器类型

| 类型 | 伤害 | 速度 | 特性 | 推荐维度 |
|------|------|------|------|---------|
| **Factor 剑** | 中等 | 快 | Factor 伤害加成 | 全维度 |
| **维度锤** | 高 | 慢 | 破甲效果 | 下界/末地 |
| **共振弓** | 中等 | 中 | 远程 Factor 冲击 | 主世界 |
| **仲裁刃** | 极高 | 中 | 维度穿透 | 末地 |

### 材质等级

| 等级 | 名称 | 伤害加成 | 耐久度 | 获取方式 |
|------|------|---------|--------|---------|
| T1 | 粗坯级 | +20% | 500 | 基础共振炉 |
| T2 | 工业级 | +40% | 1000 | 维度结晶器 |
| T3 | 维度级 | +60% | 2000 | 远古合成阵 |
| T4 | 远古级 | +80% | 3000 | 仲裁反应堆 |
| T5 | 仲裁级 | +100% | 5000 | 终局内容 |

### Factor 伤害公式

```
实际伤害 = 基础伤害 × (1 + Factor 加成) × (1 + 维度加成)

Factor 加成 = 当前维度 Factor 值 / 100 × 武器系数
维度加成 = 推荐维度？1.0 : 0.5
```

```
基础行为树:

├── 攻击判断
│   ├── 近战：直接攻击
│   ├── 远程：投射物
│   └── 特殊：维度技能
└── 撤退条件 (Factor 过低)
```

## ⚖️ 平衡性设计

### 伤害平衡

```
T1 武器 vs T1 怪物：4-6 次攻击击杀
T2 武器 vs T2 怪物：5-7 次攻击击杀
T3 武器 vs T3 怪物：6-8 次攻击击杀
T4 武器 vs T4 怪物：8-10 次攻击击杀
T5 武器 vs T5 怪物：10-12 次攻击击杀
```

### Factor 加成影响

```
Factor 0-30 ( depleted):  无加成
Factor 30-50 (low):       +10% 伤害
Factor 50-70 (stable):    +25% 伤害
Factor 70-90 (high):      +50% 伤害
Factor 90-100 (overload): +100% 伤害
```

### 维度惩罚

```
推荐维度：100% 伤害
非推荐维度：50% 伤害
极端维度 (主世界 T4+): 25% 伤害
```

## 🎮 玩家体验

### 新手引导

1. **第 1 天** - 获得 T1 武器，击败因子畸变体
2. **第 3 天** - 升级到 T2 武器，探索下界
3. **第 7 天** - 获得 T3 武器，挑战末地
4. **第 14 天** - T4 武器，准备终局

### 难度曲线

```
前期 (T1-T2): 教学为主，低压力
中期 (T3): 挑战性增加，需要策略
后期 (T4-T5): 高难度，需要完整 Build
```
