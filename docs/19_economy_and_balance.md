### 平衡公式

```
净 Factor 收益 = 释放产出 - 吸收消耗

推荐维度生产：
- 主世界生产 T1: 1000 点消耗
- 下界生产 T2: 5000 点消耗
- 末地生产 T4: 125000 点消耗

非推荐维度生产 (×10 惩罚):
- 主世界生产 T2: 50000 点消耗
- 成本增加：10 倍
```

### 跨维度优化收益

```
场景：在主世界生产 Lv3 材料

方案 A：直接生产 (非推荐维度)
- 消耗：50000 点 Factor
- 产出：1 份 Lv3 材料

方案 B：从下界传输后生产
- 下界发送：39062 点 Factor
- 主世界接收：39062 × 3 × 0.8 = 93750 点
- 实际消耗：50000 点
- 优化收益：节省 58% 下界 Factor

结论：跨维度传输可优化成本，但操作复杂
```

## 终局资源出口

### 资源消耗途径

| 消耗途径 | 消耗速率 | 说明 |
|---------|---------|------|
| 终局合成 | 125000 点/次 | Lv4→Lv5 材料 |
| 自定义维度 | 500000 点/创建 | 一次性消耗 |
| 跨维度传输 | 10000-50000 点/小时 | 持续消耗 |
| 灾害应对 | 5000-20000 点/次 | 应急消耗 |

### 通胀控制

```
机制 1: 材料回收损耗
- 回收效率：约 70%
- 损耗：30%
- 作用：防止无限循环

机制 2: 跨维度传输损耗
- 基础损耗：5-20%
- 距离损耗：0.3-1%/100 格
- 作用：限制无限套利

机制 3: 终局消耗
- 自定义维度创建：大量消耗
- 终局巨构维护：持续消耗
- 作用：长期资源出口
```
