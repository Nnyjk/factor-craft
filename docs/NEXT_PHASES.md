# Factor Craft 后续阶段规划

> 创建日期: 2026-03-22
> 状态: 规划中

---

## 设计目标

1. **游戏内容充足** - 足够多的可玩内容
2. **游戏玩法丰富** - 多样的游戏机制
3. **设定逻辑自洽** - 世界观统一，系统间有逻辑关联

---

## 决策记录

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 贴图方案 | 占位形式 | 使用占位贴图，后续替换 |
| 职业解锁 | 首次进入世界选择 | 简单直接，不可更改 |

## 阶段规划

### Phase M: 职业系统实现 ⭐核心

**目标**: 实现三大职业完整功能

**设计文档**: `docs/designs/class_system.md`

#### M1. 职业基础框架

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 职业注册系统 | Profession 数据结构、注册表 | 高 |
| 职业选择 UI | 首次登录弹出选择界面 | 高 |
| 职业数据存储 | NBT 存储玩家职业信息 | 高 |
| 职业属性系统 | 基础属性 + 职业属性 + 派生属性 | 高 |

**职业列表**:
- 创生者 (Genesis) - 生命与生长
- 湮灭者 (Oblivion) - 虚空与毁灭
- 锻铸师 (Forge) - 转化与重塑

#### M2. 天赋系统

**结构**: 每职业 3 条天赋路线，每路线 5 层

```
解锁等级: 5 → 10 → 20 → 30 → 50
天赋点: 每升 5 级获得 1 点
```

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 天赋数据结构 | Talent 节点、树结构 | 高 |
| 天赋树 UI | 可视化天赋树界面 | 中 |
| 天赋效果实现 | 各职业 45 个天赋效果 | 中 |
| 天赋点管理 | 分配、重置机制 | 中 |

#### M3. 技能系统

**主动技能**: 每职业 6 个，消耗 Factor 释放

| 职业 | 技能方向 |
|------|----------|
| 创生者 | 治愈、召唤、增益 |
| 湮灭者 | 伤害、虚空、范围 |
| 锻铸师 | 强化、制造、改造 |

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 技能数据结构 | Skill 定义、冷却、消耗 | 中 |
| 技能释放机制 | 快捷键绑定、目标选择 | 中 |
| 技能 UI | 技能栏、冷却显示 | 低 |
| 各职业技能实现 | 18 个主动技能 | 低 |

#### M4. 被动效果

**被动技能**: 每职业 4 个，自动生效

| 任务 | 优先级 |
|------|--------|
| 被动效果注册 | 低 |
| 12 个被动效果实现 | 低 |

#### M5. 职业成长系统

**等级体系**: 1-100 级，双资源消耗（经验 + Factor）

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 等级系统 | 经验获取、升级逻辑 | 高 |
| 升级消耗 | 经验 + Factor 双资源公式 | 高 |
| 里程碑奖励 | 等级解锁天赋/技能槽 | 中 |
| 属性点分配 | UI 和逻辑 | 中 |
| 生活技能 | 行为追踪、等级提升 | 低 |
| 归元系统 | 重置天赋/属性点 | 低 |

| 合力击杀 | 2+ | 多人共同击败 Boss | 掉落 ×1.5 |
| 资源共享 | 3+ | 通过传递器共享 Factor | 经验共享 |

##### Factor 网络

| 功能 | 描述 |

| 网络监控 | 可查看网络中的 Factor 流动 |

### Phase P: 设定自洽化

**目标**: 确保世界观和系统逻辑统一

#### P1. 世界观整合

##### 职业起源故事

**创生者起源**:
> 在废弃文明的遗迹深处，幸存者发现了一种能与 Factor 中"生命脉动"共鸣的方法。这些先驱者学会了引导 Factor 的创生之力，让荒芜的土地重新焕发生机。他们被称为创生者——相信 Factor 是远古文明遗留的生命种子。

**湮灭者起源**:
> 有些探索者选择了不同的道路。他们深入 Factor 的"毁灭面"，发现 Factor 本质上是一种衰变能量。湮灭者拥抱这种毁灭之力，明白只有通过破坏才能腾出空间让新事物诞生。他们驾驭虚空能量，成为 Factor 的毁灭化身。

**锻铸师起源**:
> 第三条道路由工匠们开创。他们发现 Factor 不仅是能量，更是"转化的媒介"。通过精密的机器和符文，锻铸师学会了用 Factor 重塑物质，将原本无用的废料转化为珍贵的材料。

##### 职业与 Factor 关联

| 职业 | Factor 理解 | 能量类型 |
|------|-------------|----------|
| 创生者 | Factor = 生命种子 | 正熵能量 |
| 湮灭者 | Factor = 毁灭余烬 | 负熵能量 |
| 锻铸师 | Factor = 转化媒介 | 中性能量 |

##### 废弃文明设定

**核心设定**:
- Factor 是远古文明遗留的能量形式
- 三大职业代表了远古文明的三个派系
- 机器是远古科技的重建
- 玩家是"继承者"，重建失落的文明

##### 文案更新任务

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 职业选择界面文案 | 三职业介绍文本 | 高 |
| 引导书世界观章节 | 整合后的世界观 | 高 |
| 成就描述更新 | 与设定一致的文案 | 中 |
| 物品描述更新 | 添加背景故事 | 低 |
| NPC 对话 | 如有 NPC，更新对话 | 低 |

#### P2. 进度系统设计

**核心原则**: 每次 Tier 提升都带来充足的收获感

##### 收获感设计

**原则**: 到达下一等级后，获取上一等级的材料/物品变得显著更容易

| 升级后 | 获得的简化 |
|--------|-----------|
| T2 完成 | T1 材料产量 ×2，T1 机器效率 ×1.5 |
| T3 完成 | T1-T2 材料产量 ×2，解锁自动合成基础材料 |
| T4 完成 | T1-T3 材料产量 ×2，解锁一键批量生产 |
| T5 完成 | T1-T4 材料可从 Factor 直接生成 |

##### 中间节点系统

每个 Tier 设定 **2-3 个中间节点**，每个节点带来显著的简化或提升：

###### T1 粗坯阶段 (0-2小时)

| 节点 | 解锁条件 | 带来的提升 |
|------|----------|-----------|
| 节点 1.1 | 建造第一台提取器 | 解锁 Factor 收集 |
| 节点 1.2 | 收集 500 Factor | 解锁 T1 材料合成 |
| 节点 1.3 | 建造合成器 | 可将铜转化为尘铜锭 |

**阶段完成奖励**: T1 材料自动产出 (每小时 5 个尘铜锭)

###### T2 工业阶段 (2-6小时)

| 节点 | 解锁条件 | 带来的提升 |
|------|----------|-----------|
| 节点 2.1 | 升级机器至 T2 | 处理速度 ×1.5，Factor 消耗 -10% |
| 节点 2.2 | 收集 2000 Factor | 解锁暗影钢批量合成 |
| 节点 2.3 | 建造完整的 T2 机器组 | 解锁自动化生产线 |

**阶段完成奖励**: 
- T1 材料产量 ×2
- 解锁「Factor 电池」存储 Factor

###### T3 维度阶段 (6-15小时)

| 节点 | 解锁条件 | 带来的提升 |
|------|----------|-----------|
| 节点 3.1 | 进入下界 | 解锁下界 Factor 源 (浓度 ×1.5) |
| 节点 3.2 | 建造维度结晶器 | 可从下界提取维度晶体 |
| 节点 3.3 | 升级机器至 T3 | 处理速度 ×2，解锁跨维度传输 |

**阶段完成奖励**:
- T1-T2 材料可自动合成
- 解锁「Factor 网络」远程传输

###### T4 远古阶段 (15-30小时)

| 节点 | 解锁条件 | 带来的提升 |
|------|----------|-----------|
| 节点 4.1 | 进入末地 | 解锁末地 Factor 源 (浓度 ×3) |
| 节点 4.2 | 击败末地 Boss | 获得远古核心，解锁 T4 合成 |
| 节点 4.3 | 建造远古祭坛 | 解锁特性注入上限 +1 |

**阶段完成奖励**:
- T1-T3 材料一键批量生产
- 解锁「Factor 共鸣」范围效果

###### T5 仲裁阶段 (30-50小时)

| 节点 | 解锁条件 | 带来的提升 |
|------|----------|-----------|
| 节点 5.1 | 收集虚空结晶 | 解锁虚空能量操控 |
| 节点 5.2 | 建造虚空漩涡 | 可直接从虚空提取 Factor |
| 节点 5.3 | 完成所有 T5 机器 | 解锁「Factor 精通」全属性 +20% |

**阶段完成奖励**:
- 所有基础材料可从 Factor 直接生成
- 解锁「突破阶段」

##### 突破阶段 (终极内容)

**目标**: 难度极大的挑战，完成后获得"创造"体验

###### 突破条件

| 条件 | 描述 |
|------|------|
| 全机器 T5 | 所有机器升级至 T5 |
| 职业满级 | 达到职业等级 100 |
| Factor 储备 | 累计存储 1,000,000 Factor |
| 成就完成 | 完成 80% 以上成就 |
| Boss 征服 | 击败所有 Boss |

###### 突破挑战

**挑战名称**: 「本源仪式」

| 阶段 | 内容 | 难度 |
|------|------|------|
| 第一阶段 | 同时运转所有 T5 机器 1 小时 | 资源管理 |
| 第二阶段 | 在过载潮汐中存活并维持机器运转 | 生存挑战 |
| 第三阶段 | 击败「Factor 仲裁者」(生命值 5000) | 战斗挑战 |
| 第四阶段 | 消耗所有储备 Factor 完成仪式 | 资源投入 |

###### 突破奖励：「Factor 主宰」

| 能力 | 描述 |
|------|------|
| Factor 无限 | Factor 容量无限，自然恢复 |
| 物质重构 | 可将任意物品转化为 Factor |
| 因子创生 | 可从 Factor 直接生成任意物品 |
| 维度行走 | 瞬间传送到任意已探索位置 |
| 潮汐掌控 | 可自由切换当前潮汐状态 |
| 职业全修 | 可同时拥有三职业能力 |

**体验目标**: 从"Factor 的使用者"变为"Factor 的主宰者"
