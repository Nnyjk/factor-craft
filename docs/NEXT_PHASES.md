# Factor Craft 后续阶段规划

> 创建日期: 2026-03-22
> 状态: 规划中

---

## 设计目标

1. **游戏内容充足** - 足够多的可玩内容
2. **游戏玩法丰富** - 多样的游戏机制
3. **设定逻辑自洽** - 世界观统一，系统间有逻辑关联

## 阶段规划

### Phase M: 职业系统实现 ⭐核心

**目标**: 实现三大职业完整功能

**设计文档**: `docs/designs/class_system.md`

#### M1. 职业基础框架

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 职业注册系统 | Profession 数据结构、注册表 | 高 |
| 职业选择 UI | 首次登录弹出选择界面 | 高 |
| 职业数据存储 | NBT 存储玩家职业信息 | 高 |
| 职业属性系统 | 基础属性 + 职业属性 + 派生属性 | 高 |

**职业列表**:
- 创生者 (Genesis) - 生命与生长
- 湮灭者 (Oblivion) - 虚空与毁灭
- 锻铸师 (Forge) - 转化与重塑

#### M2. 天赋系统

**结构**: 每职业 3 条天赋路线，每路线 5 层

```
解锁等级: 5 → 10 → 20 → 30 → 50
天赋点: 每升 5 级获得 1 点
```

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 天赋数据结构 | Talent 节点、树结构 | 高 |
| 天赋树 UI | 可视化天赋树界面 | 中 |
| 天赋效果实现 | 各职业 45 个天赋效果 | 中 |
| 天赋点管理 | 分配、重置机制 | 中 |

#### M3. 技能系统

**主动技能**: 每职业 6 个，消耗 Factor 释放

| 职业 | 技能方向 |
|------|----------|
| 创生者 | 治愈、召唤、增益 |
| 湮灭者 | 伤害、虚空、范围 |
| 锻铸师 | 强化、制造、改造 |

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 技能数据结构 | Skill 定义、冷却、消耗 | 中 |
| 技能释放机制 | 快捷键绑定、目标选择 | 中 |
| 技能 UI | 技能栏、冷却显示 | 低 |
| 各职业技能实现 | 18 个主动技能 | 低 |

#### M4. 被动效果

**被动技能**: 每职业 4 个，自动生效

| 任务 | 优先级 |
|------|--------|
| 被动效果注册 | 低 |
| 12 个被动效果实现 | 低 |

### Phase N: 内容填充

**目标**: 填充游戏内容，提供充足的可玩内容

#### N1. 任务内容填充

**当前状态**: 框架完成，内容空

| 类型 | 目标数量 | 内容方向 |
|------|----------|----------|
| 主线任务 | 15+ | 引导玩家了解 Factor 系统 |
| 日常任务 | 10+ | Factor 收集、机器操作 |
| 成就任务 | 10+ | 达成特定目标 |
| 职业任务 | 9+ | 每职业 3 条任务线 |

| 任务类型 | 示例 |
|----------|------|
| 收集类 | 收集 64 个 Factor 碎片 |
| 建造类 | 建造第一台提取器 |
| 探索类 | 找到 3 个高浓度区块 |
| 战斗类 | 击败 Factor 守护者 |
| 职业类 | 使用职业技能 10 次 |

#### N2. 配方平衡调整

**目标**: 确保 T1-T5 进度曲线合理

| 内容 | 说明 |
|------|------|
| 材料升级配方 | T1→T2→T3→T4→T5 消耗和产出 |
| 机器效率 | 各等级机器的处理速度 |
| Factor 消耗 | 各操作的 Factor 成本 |

#### N3. 怪物掉落表完善

**当前状态**: 基础完成

| 怪物类型 | 掉落内容 |
|----------|----------|
| 普通怪物 | Factor 碎片 (低概率) |
| 高浓度区域怪物 | Factor 碎片 (高概率) |
| Boss | Factor 核心、稀有材料 |
| 职业相关怪物 | 职业专属材料 |

#### N4. 引导书内容扩充

**目标**: 让玩家能通过引导书了解所有系统

| 章节 | 内容 |
|------|------|
| Factor 入门 | 基础概念、浓度、潮汐 |
| 机器系统 | 各机器用法、多方块结构 |
| 材料系统 | T1-T5 材料获取与用途 |
| 职业系统 | 三职业介绍、天赋、技能 |
| 战斗系统 | 武器、怪物、Boss |

---

### Phase O: 玩法丰富化

**目标**: 增加游戏深度和可玩性

#### O1. 成就系统扩展

**目标**: 与职业系统挂钩

| 类型 | 内容 |
|------|------|
| 通用成就 | 玩家进度里程碑 |
| 职业成就 | 每职业专属成就 |
| 隐藏成就 | 特殊条件触发 |

#### O2. 挑战内容

| 内容 | 描述 |
|------|------|
| Boss 战增强 | 多阶段 Boss、特殊机制 |
| 限时任务 | 潮汐事件期间的特殊任务 |
| 挑战模式 | 高难度区域、高回报 |

#### O3. 社交系统 (多人)

| 内容 | 描述 |
|------|------|
| 组队加成 | 同职业/不同职业组队效果 |
| 协作任务 | 需要多人完成的大型任务 |
| Factor 网络 | 玩家间 Factor 传输 |

---

### Phase P: 设定自洽化

**目标**: 确保世界观和系统逻辑统一

#### P1. 世界观整合

**任务**: 将职业系统融入现有世界观

| 内容 | 说明 |
|------|------|
| 职业起源故事 | 三职业与 Factor 的关系 |
| 与废弃文明设定的关联 | 职业是远古遗产还是新发现 |
| 游戏内文案更新 | NPC、引导书、成就描述 |

#### P2. 数值体系验证

| 检查项 | 说明 |
|--------|------|
| Factor 经济 | 产出 vs 消耗是否平衡 |
| 进度曲线 | T1→T5 时间成本是否合理 |
| 职业平衡 | 三职业强度是否均衡 |

#### P3. 文案统一

| 内容 | 检查项 |
|------|--------|
| 物品描述 | 与设定一致 |
| 成就文本 | 与世界观一致 |
| UI 文本 | 术语统一 |

## 实现优先级

### 第一优先级 (核心玩法)

| Phase | 内容 | 原因 |
|-------|------|------|
| M1 | 职业基础框架 | 核心系统，其他内容依赖它 |
| M2 | 天赋系统 | 职业核心玩法 |

### 第二优先级 (内容填充)

| Phase | 内容 | 原因 |
|-------|------|------|
| N1 | 任务内容 | 让玩家有目标 |
| N2 | 配方平衡 | 游戏可玩性 |
| N4 | 引导书 | 玩家引导 |

### 第三优先级 (丰富化)

| Phase | 内容 | 原因 |
|-------|------|------|
| M3 | 技能系统 | 职业深度 |
| N3 | 怪物掉落 | 战斗动力 |
| O1 | 成就扩展 | 长期目标 |

### 第四优先级 (完善)

| Phase | 内容 | 原因 |
|-------|------|------|
| M4 | 被动效果 | 锦上添花 |
| O2 | 挑战内容 | 高级内容 |
| O3 | 社交系统 | 多人增强 |
| P | 设定自洽 | 最终打磨 |
