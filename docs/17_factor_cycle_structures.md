## 17.0 核心设计理念

### Factor 循环生态系统

```
┌─────────────────────────────────────────────────────────────┐
│                    Factor 循环生态系统                       │
│                                                             │
│   吸收结构 (消耗 Factor)          释放结构 (产生 Factor)     │
│         ↓                              ↑                     │
│   生产科技材料                    消耗方块/材料              │
│         ↓                              ↑                     │
│   需要前一级材料基础              按维度等级倍率             │
│         ↓                              ↑                     │
│   └──────────→ 跨维度传递 ←───────────┘                     │
│                (Factor 传输)                                 │
└─────────────────────────────────────────────────────────────┘
```

### 设计目标

1. **Factor 可循环** - 不是单向消耗，而是可再生的资源
2. **维度联动** - 通过 Factor 流动创造跨维度依赖
3. **策略深度** - 玩家需管理 Factor 供需平衡
4. **惩罚可控** - 维度惩罚有倍率但可通过跨维度传递优化

### Factor 数值体系

**基础概念：**
- Factor 是维度稳定度的数值表现（无单位）
- 不同维度有不同的 Factor 基准值
- 跨维度传输存在倍率转换

**维度基准值（以 1.0 为基准）：**

| 维度 | 基准值 | 潮汐周期 | 波动幅度 | Factor 范围 |
|------|--------|---------|---------|------------|
| 主世界 | **0.5** | 8 天 | ±0.2 | 0.3 - 0.7 |
| 下界 | **1.5** | 4 天 | ±0.6 | 0.9 - 2.1 |
| 末地 | **3.0** | 12 天 | ±1.2 | 1.8 - 4.2 |

**维度倍率机制：**

从高基准值维度向低基准值维度传输时：
```
接收端 Factor = 发送端 Factor × (发送端基准 / 接收端基准) × 传递器效率

示例：
- 从下界 (基准 1.5) 传输到主世界 (基准 0.5)
- 传输倍率 = 1.5 / 0.5 = 3.0
- 下界发送：1000 点
- 传递器效率：80%
- 主世界接收 = 1000 × 3.0 × 0.8 = 2400 点
```

从低基准值维度向高基准值维度传输时：
```
接收端 Factor = 发送端 Factor × (发送端基准 / 接收端基准) × 传递器效率

示例：
- 从末地 (基准 3.0) 传输到主世界 (基准 0.5)
- 传输倍率 = 3.0 / 0.5 = 6.0
- 末地发送：1000 点
- 传递器效率：85%
- 主世界接收 = 1000 × 6.0 × 0.85 = 5100 点
```

**维度惩罚机制：**

在非推荐维度生产材料时，Factor 消耗倍率：

| 生产等级 | 推荐维度 | 基准值 | 非推荐维度倍率 |
|---------|---------|--------|---------------|
| T1 (Lv1→Lv2) | 主世界 | 0.5 | 下界/末地 ×10 |
| T2 (Lv2→Lv3) | 下界 | 1.5 | 主世界/末地 ×10 |
| T3 (Lv3→Lv4) | 下界/末地 | 1.5/3.0 | 主世界 ×10 |
| T4 (Lv4→Lv5) | 末地 | 3.0 | 主世界/下界 ×10 |

**传输倍率表：**

| 传输方向 | 传输倍率 |
|---------|---------|
| 下界 → 主世界 | 1.5 / 0.5 = **×3** |
| 末地 → 主世界 | 3.0 / 0.5 = **×6** |
| 末地 → 下界 | 3.0 / 1.5 = **×2** |
| 主世界 → 下界 | 0.5 / 1.5 = **×0.33** |
| 主世界 → 末地 | 0.5 / 3.0 = **×0.17** |
| 下界 → 末地 | 1.5 / 3.0 = **×0.5** |

**跨维度 Factor 优化示例：**

```
场景：在主世界生产 T3 材料（本应在下界生产）

方案 1：直接生产
- 主世界 Factor 基准：0.5
- 消耗倍率：×10
- 需要消耗：50000 点 Factor

方案 2：从下界传输后生产
- 下界 Factor 基准：1.5
- 从下界传输 1000 点到主世界
- 接收 Factor = 1000 × (1.5/0.5) × 0.8 = 2400 点
- 在主世界生产消耗：50000 点
- 需要传输次数：50000 / 2400 ≈ 21 次
- 总消耗：21000 点下界 Factor

优化效果：节省 58% 下界 Factor（但传输操作更复杂）
```

## 17.1 吸收 Factor 的多方块结构（Factor Sink）

### 设计原则

- 使用**前一级科技材料**建造
- 生产**当前等级材料**
- 消耗 Factor 转化为物质

### 结构总览

| 结构名称 | 科技等级 | 基础材料 | 产物材料 | 基础 Factor 消耗 | 推荐维度 | 基准值 |
|---------|---------|---------|---------|----------------|----------|--------|
| **基础共振炉** | T1 | Lv1 粗坯级 | Lv2 工业级 | 1000 点/批次 | 主世界 | 0.5 |
| **维度结晶器** | T2 | Lv2 工业级 | Lv3 维度级 | 5000 点/批次 | 下界 | 1.5 |
| **远古合成阵** | T3 | Lv3 维度级 | Lv4 远古级 | 25000 点/批次 | 下界/末地 | 1.5/3.0 |
| **仲裁反应堆** | T4 | Lv4 远古级 | Lv5 仲裁级 | 125000 点/批次 | 末地 | 3.0 |

### Factor 消耗计算

```
实际消耗 = 基础消耗 × 维度惩罚 × (1 - 环境加成)

维度惩罚：
- 推荐维度：×1.0
- 非推荐维度：×10

环境加成：
- Factor 在推荐窗口：-20%
- ΔF 30-50：-10%
- ΔF 50+：-15%
```

### 17.1.1 基础共振炉（T1）

**功能：** 将 Lv1 材料转化为 Lv2 材料

**建造材料：**
- 粗坯级材料 ×64（铜、青铜、石英强化木芯）
- 基础共振件 ×4
- 因子计 ×1（核心）

**合成配方：**
```
输入                    输出
─────────────────────────────────────
铜矿石 ×10              铁锭 ×5
青铜锭 ×5               下界石钢锭 ×3
石英强化木芯 ×20        铁锭 ×8 + 木炭 ×10

基础转换率：2:1（2 份 Lv1 → 1 份 Lv2）
```

**Factor 消耗：**
```
基础消耗：1000 点/批次
维度惩罚：
  - 主世界（推荐）：×1.0 → 1000 点
  - 下界：×10 → 10000 点
  - 末地：×10 → 10000 点

环境加成：
  - Factor 50-70（稳定窗口）：-20% → 800 点
  - ΔF 30-50：-10% → 900 点
  - ΔF 50+：-15% → 850 点

最低消耗：1000 × 0.8 × 0.85 = 680 点
最高消耗：1000 × 10 = 10000 点
```

**使用场景：**
- 早期工业基础材料生产
- 主世界稳定环境下推荐

## 17.2 释放 Factor 的多方块结构（Factor Source）

### 设计原则

- 消耗各类方块/材料
- 向环境释放 Factor
- 维度倍率影响释放效率

### 结构总览

| 结构名称 | 科技等级 | 消耗材料 | Factor 释放 | 释放速率 | 推荐维度 |
|---------|---------|---------|------------|---------|---------|
| **基础共振器** | T1 | 石头、煤炭 | +50 | 1 批次/个 | 主世界 |
| **能量分解机** | T2 | 铁、红石 | +150 | 2 批次/个 | 主世界/下界 |
| **物质转化炉** | T3 | 钻石、下界合金 | +500 | 5 批次/个 | 下界 |
| **维度裂变器** | T4 | Lv3+ 材料 | +2000 | 10 批次/个 | 末地 |

### 维度倍率机制

```
实际释放 = 基础释放 × 维度倍率 × 材料品质系数

维度倍率：
- 主世界：×1.0（基准）
- 下界：×1.5（高能环境加成）
- 末地：×2.0（精密环境加成）

材料品质系数：
- 普通品质：×1.0
- 高纯度（ΔF > 40 时生产）：×1.2
- 完美品质（ΔF > 70 时生产）：×1.5
```

## 17.3 跨维度传递器（Factor Transmitter）

### 设计原则

- 用**当前维度最高阶材料**制作
- 将 Factor 传递至**其他维度**
- 效率随科技等级提升

### 传递器总览

| 传递器类型 | 制作材料 | 基础效率 | 距离损耗 | 说明 |
|-----------|---------|---------|---------|------|
| **T1 传递器** | Lv2 工业级 | 80% | -1%/100 格 | 基础跨维度传输 |
| **T2 传递器** | Lv3 维度级 | 85% | -0.8%/100 格 | 效率提升 |
| **T3 传递器** | Lv4 远古级 | 90% | -0.5%/100 格 | 高效传输 |
| **T4 传递器** | Lv5 仲裁级 | 95% | -0.3%/100 格 | 终极传输 |

### 传递公式

**高→低传输（下界→主世界）：**
```
接收 Factor = 发送 Factor × (发送维度基准 / 接收维度基准) × 效率

示例：
- 从下界 (基准 80) 传输到主世界 (基准 50)
- 发送：1000 点
- 倍率 = 80 / 50 = 1.6
- 效率：80%
- 接收 = 1000 × 1.6 × 0.8 = 1280 点
```

**低→高传输（末地→主世界）：**
```
接收 Factor = 发送 Factor × (接收维度基准 / 发送维度基准) × 效率

示例：
- 从末地 (基准 20) 传输到主世界 (基准 50)
- 发送：1000 点
- 倍率 = 50 / 20 = 2.5
- 效率：85%
- 接收 = 1000 × 2.5 × 0.85 = 2125 点
```

### 战略应用

**场景 1：主世界生产 T3 材料**
```
目标：在主世界生产 Lv3 材料（本应在下界）

直接生产：
- 消耗：5000 × 10 = 50000 点主世界 Factor

从下界传输：
- 下界发送：39062 点
- 主世界接收：39062 × 1.6 × 0.8 ≈ 50000 点
- 节省：主世界 Factor 基准不足时可用下界补充

结论：跨维度传递可以优化 Factor 分配，但不会降低总成本
```

**场景 2：利用末地稳定环境**
```
目标：在末地生产 Lv5 材料（推荐维度）

末地生产：
- 消耗：125000 点末地 Factor

末地 Factor 不足时的解决方案：
- 从下界传输：125000 / 1.6 / 0.9 ≈ 86805 点下界 Factor
- 从主世界传输：125000 / 0.4 / 0.85 ≈ 367647 点主世界 Factor

结论：高 Factor 维度向低 Factor 维度传输更高效
```

## 17.4 Factor 循环战略应用

### 场景 1：维度 Factor 平衡

```
目标：维持三维度 Factor 稳定

策略：
1. 主世界（基准 50）：基础共振器维持，生产 T1 材料
2. 下界（基准 80）：物质转化炉补充，生产 T2-T3 材料
3. 末地（基准 20）：维度裂变器放大，生产 T4 材料

循环：
- 主世界过剩 Lv1 材料 → 基础共振器 → Factor → 基础共振炉 → Lv2 材料
- 下界生产 Lv3 材料 → 过剩传输至主世界/末地
- 末地利用低基准优势，释放结构倍率×2.0
```

---

### 场景 2：材料回收循环

```
目标：将过剩的低阶材料升级为高阶材料

流程：
1. 过剩 Lv2 材料 → 能量分解机 → Factor
   - 铁锭 ×100 → +10000 Factor（主世界）
   
2. Factor → 维度结晶器 → Lv3 材料
   - 消耗 5000 Factor
   - 产出：钴锭 ×2（转换率 4:1）

损耗分析：
- 释放效率：80%（设备损耗）
- 吸收效率：90%（设备损耗）
- 总损耗：约 28%

适用：清理库存、材料升级
```
