# R2.4: 成就系统

## 任务描述

实现 Factor Craft 专属的成就/进度系统，追踪玩家在 Factor 探索、科技研发、终局内容方面的进展。

## 功能需求

### 成就类别
1. **Factor 探索**: Factor 发现、提取、浓缩、压缩等里程碑
2. **科技研发**: 机器解锁、自动化建立、物流网络等
3. **终局内容**: TΩ 突破、量子装备、终局机器等
4. **挑战成就**: 速通、无死亡、极限模式等

### 成就 UI
- **成就树**: 可视化成就依赖关系
- **进度追踪**: 显示当前成就完成度
- **奖励系统**: 完成成就获得 Factor 点数或特殊物品
- **统计面板**: 显示游戏统计数据

### 成就触发
- **自动检测**: 物品获取、方块放置、浓度检测等
- **条件检查**: 支持多条件组合 (AND/OR)
- **进度保存**: 成就进度随玩家数据保存

## 技术规格

### 成就数据结构
```json
{
  "id": "factorcraft:factor_discovery",
  "title": "Factor 发现者",
  "description": "首次提取 Factor 晶体",
  "icon": "factorcraft:factor_crystal",
  "category": "exploration",
  "parent": null,
  "criteria": {
    "type": "item_obtained",
    "item": "factorcraft:factor_crystal",
    "count": 1
  },
  "reward": {
    "type": "factor_points",
    "amount": 10
  }
}
```

### 成就类别
| 类别 | 成就数量 | 描述 |
|------|----------|------|
| exploration | 10 | Factor 探索相关 |
| technology | 15 | 科技研发相关 |
| endgame | 10 | 终局内容相关 |
| challenge | 5 | 挑战成就 |
