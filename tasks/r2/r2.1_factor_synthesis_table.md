# R2.1: Factor 合成台

## 任务描述

实现 TΩ 级 Factor 合成设备，支持使用高密度 Factor 进行高级配方合成。

## 功能需求

### 核心功能
- **多方块结构**: 3x3x3 合成台框架
- **Factor 消耗**: 使用 DenseFactor 作为合成能源
- **高级配方**: 支持 TΩ 级物品合成（终极工具、量子装备等）
- **GUI 界面**: 显示合成进度、Factor 储量、配方列表

### 技术规格
- **结构验证**: 检测 3x3x3 多方块结构完整性
- **合成时间**: 根据配方复杂度，100-600 ticks
- **Factor 消耗**: 每个配方消耗 10-100 mB DenseFactor
- **内部缓存**: 10,000 mB DenseFactor 存储

### 合成配方示例
1. **量子工具**: 钻石工具 + DenseFactor x 10 mB
2. **Factor 盔甲**: 下界合金盔甲 + DenseFactor x 20 mB
3. **终局机器核心**: 高级电路 + DenseFactor x 50 mB
