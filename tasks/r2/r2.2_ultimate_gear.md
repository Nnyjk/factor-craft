# R2.2: 终极装备

## 任务描述

实现 Factor 驱动的终极工具和盔甲，提供超越下界合金的性能和特殊能力。

## 功能需求

### 终极工具 (Quantum Tools)
- **工具类型**: 稿、斧、铲、锄、剑
- **基础属性**: 超越下界合金的挖掘速度和伤害
- **特殊能力**: 
  - 范围挖掘 (3x3, 5x5 可选)
  - 自动补种 (锄头)
  - 路径创建 (铲子)
  - 树干砍伐 (斧头)
- **耐久度**: 10,000 (可修复)
- **附魔兼容性**: 支持标准附魔

### 终极盔甲 (Factor Armor)
- **盔甲部位**: 头盔、胸甲、护腿、靴子
- **基础属性**: 超越下界合金的防护值
- **套装效果**:
  - 2 件：Factor 浓度感知
  - 4 件：Factor 护盾 (吸收伤害)
- **耐久度**: 每件 5,000
- **附魔兼容性**: 支持标准附魔

### 充能机制
- **充能物品**: DenseFactor 或 Factor 水晶
- **充能 GUI**: 显示当前充能等级
- **充能消耗**: 每次特殊能力使用消耗 1-5 mB DenseFactor

1. 工具继承 `PickaxeItem` 等基础类，添加特殊能力
2. 使用 Data Components 存储充能状态
3. 范围挖掘参考 VeinMiner 逻辑
4. 套装效果使用 `ArmorItem` 的 `onEquip`/`onRemoved` 方法
