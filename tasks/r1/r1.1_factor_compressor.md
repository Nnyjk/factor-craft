# R1.1: Factor 压缩机实现

**Issue**: #286  
**优先级**: P0 高  
**预计文件**: 4

---

## 目标

实现 Factor 压缩机，将低浓度 Factor 压缩为高密度形态，用于高级合成。

---

## 功能需求

1. **多方块结构** - 3x3x3 的压缩机结构
2. **Factor 输入** - 接受 1000mB 普通 Factor
3. **压缩输出** - 输出 10mB 高密度 Factor (压缩比 100:1)
4. **能量需求** - 需要 Factor 浓度驱动
5. **动画效果** - 工作时显示压缩动画

---

## 实现步骤

### 1. 创建 DenseFactor 物品

- 定义高密度 Factor 物品
- 设置 registryKey
- 添加 Data Components

### 2. 创建 FactorCompressorBlock

- 实现多方块结构检测
- 添加 Block Settings (registryKey)
- 实现 getCodec() 方法

### 3. 创建 FactorCompressorBlockEntity

- 实现 Factor 存储逻辑
- 实现压缩逻辑 (1000mB → 10mB)
- 实现 writeNbt/readNbt (带 WrapperLookup)

### 4. 创建 FactorCompressorScreenHandler

- 实现 UI 界面
- 添加 Factor 槽位
- 添加输出槽位

---

## API 注意事项

- `Item.Settings` 需要 `.registryKey(key)`
- `Block.Settings.create()` 需要 `.registryKey(key)`
- `BlockWithEntity.getCodec()` 使用 `createCodec(ClassName::new)`
- `writeNbt/readNbt` 需要 `RegistryWrapper.WrapperLookup` 参数
- 使用 Data Components 替代 NBT
