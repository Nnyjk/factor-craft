# R1.3 Factor 注射器

## 任务描述

实现 Factor 注射器，用于为工具/装备注入 Factor，获得临时特殊能力。

## 功能特性

- **注射器物品**: `FactorInjectorItem` - 手持设备，用于注射 Factor
- **注射逻辑**: 对工具/装备使用，注入 Factor 获得增益
- **增益效果**: 
  - 工具：增加挖掘速度、耐久度
  - 武器：增加伤害、火焰附加
  - 盔甲：增加防护、特殊抗性
- **持续时间**: 基于注入的 Factor 量，最长 5 分钟
- **Data Component**: `FACTOR_INJECTION` 存储注射信息

## 验收标准

- [ ] 编译通过
- [ ] 注射器可合成
- [ ] 注射后工具获得临时增益
- [ ] 增益效果有时间限制

## 技术要点

- Fabric 1.21.4 Data Components API
- `Item.Settings` 需要 `.registryKey(key)`
- 增益效果使用 `ItemStack.set()` 存储
